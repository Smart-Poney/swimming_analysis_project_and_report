# EthoVisionXT_information

## Overview

This repository contains all the data needed to re-do analysis of behaviour tests using the EthoVisionXT software distributed by NOLDUS <*https://www.noldus.com/*>. The recording of behaviour are not provided as the files were too big to be stored (~800Go). The trial list and parameters implemented are directly saved in the experiment folder `FG_calibration_comportement`. The software was used to analyse 5 minutes of behaviour recording while tracking the fish movements and displacements of the head, center and tail. Variables and coordinates were extracted from EthoVision and analysed using R software.
