# EthoVisionXT_information

## Présentation


Ce dépôt contient toutes les données nécessaires pour refaire l'analyse des tests comportementaux réalisés avec le logiciel EthoVision XT, distribué par Noldus <*https://www.noldus.com/*>. Les enregistrements vidéo des comportements ne sont pas fournis, car les fichiers étaient trop volumineux pour être conservés (~800 Go). La liste des essais et les paramètres appliqués sont directement enregistrés dans le dossier d'expérience `FG_calibration_comportement`. Le logiciel a été utilisé pour analyser 5 minutes d'enregistrement comportemental tout en suivant les mouvements du poisson ainsi que les déplacements de la tête, du centre du corps et de la queue. Les variables et les coordonnées ont été extraites d'EthoVision puis analysées à l'aide du logiciel R.
